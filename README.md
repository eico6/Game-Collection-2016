# Game Collection 2016
- Collection of 12 games I've developed between 2016 - 2019.
- Written in C#, with the Unity Game Engine.
- Most games are incomplete. They were purely made for fun, and sometimes abandoned early in development.
- This repository only serves as a showcase.
- All project-files have been compressed in order to minimize storage space.
